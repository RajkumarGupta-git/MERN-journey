Terminal Basics

Terminal

Definition:
Terminal is a place where you type commands to tell the computer what to do.

---

GUI vs CLI

GUI (Graphical User Interface)

Definition:
GUI is a way to use a computer with a mouse, icons, buttons, and windows.

You can:

* Use the mouse
* Click buttons
* Open folders
* Drag and drop files

Example:
Double-click a folder to open it.

---

CLI (Command Line Interface)

Definition:
CLI is a way to use a computer by typing commands with the keyboard.

You can:

* Use the keyboard
* Type commands

Example:

```bash
mkdir CreateFolder
```

This command creates a folder named CreateFolder.

---

Why Do We Use Terminal?

Terminal is:

* Fast
* Easy for developers
* Saves time

With the Terminal, you can:

* Create folders
* Open projects
* Run programs
* Install packages
* Use Git
* Start servers

---

Directory

Definition:
Directory = Folder

---

Path

Definition:
Path is the address of a file or folder.

Example:

```text
C:\Users\Raj\Desktop\Portfolio
```

---

Command

Definition:
A command is an instruction you give to the computer.

Example:

```bash
dir
```

This command shows all files and folders in the current directory.

==================================================

Basic Terminal Commands

1. Show Current Folder

Command:
`pwd` (or `Get-Location` in PowerShell)

Meaning:
Show the current folder.

Example:
`pwd`

---

2. Show Files and Folders

Command:
`dir`

Meaning:
Show all files and folders in the current directory.

Example:
`dir`

---

3. List Files and Folders

Command:
`ls`

Meaning:
Show files and folders (Linux/macOS command, also works in PowerShell).

Example:
`ls`

---

4. Go to a Folder

Command:
`cd folderName`

Meaning:
Move into a specific folder.

Example:
`cd Desktop`

---

5. Go Back One Folder

Command:
`cd ..`

Meaning:
Move to the parent folder.

Example:
`cd ..`

---

6. Go to the Root of the Drive

Command:
`cd \`

Meaning:
Go to the root directory of the current drive.

Example:
`cd \`

---

7. Create a New Folder

Command:
`mkdir folderName`

Meaning:
Create a new folder.

Example:
`mkdir Portfolio`

---

8. Delete an Empty Folder

Command:
`rmdir folderName`

Meaning:
Delete an empty folder.

Example:
`rmdir Test`

---

9. Delete a File

Command:
`del fileName`

Meaning:
Delete a file.

Example:
`del notes.txt`

---

10. Copy a File

Command:
`copy source destination`

Meaning:
Copy a file from one location to another.

Example:
`copy a.txt b.txt`

---

11. Move or Rename a File

Command:
`move source destination`

Meaning:
Move a file to another folder or rename it.

Example:
`move a.txt Docs`

---

12. Rename a File or Folder

Command:
`ren oldName newName`

Meaning:
Change the name of a file or folder.

Example:
`ren file.txt notes.txt`

---

13. Show File Content

Command:
`type fileName`

Meaning:
Display the contents of a text file.

Example:
`type notes.txt`

---

14. Clear the Terminal Screen

Command:
`cls`

Meaning:
Clear the terminal screen.

Example:
`cls`

---

15. Print Text

Command:
`echo text`

Meaning:
Print text on the terminal.

Example:
`echo Hello`

---

16. Open Current Folder in VS Code

Command:
`code .`

Meaning:
Open the current folder in Visual Studio Code.

Example:
`code .`

---

17. Check Node.js Version

Command:
`node -v`

Meaning:
Display the installed Node.js version.

Example:
`node -v`

---

18. Check npm Version

Command:
`npm -v`

Meaning:
Display the installed npm version.

Example:
`npm -v`

---

19. Check Git Version

Command:
`git --version`

Meaning:
Display the installed Git version.

Example:
`git --version`

---

20. Install Project Packages

Command:
`npm install` or `npm i`

Meaning:
Install all project dependencies.

Example:
`npm install`

---

21. Start Development Server

Command:
`npm run dev`

Meaning:
Start the development server.

Example:
`npm run dev`

---

22. Stop a Running Program

Command:
`Ctrl + C`

Meaning:
Stop the currently running program or server.

Example:
Press `Ctrl + C`

---

23. Auto-Complete File or Folder Name

Command:
`Tab`

Meaning:
Automatically complete a file or folder name.

Example:
Type `Doc` and press `Tab`

---

24. Command History

Command:
`↑ / ↓`

Meaning:
Show the previous or next command from history.

Example:
Press the `Up Arrow` or `Down Arrow`
